🔥 주요 변경 사항 (Major Changes)
1. 크리티컬 히트 시스템(Critical Hit) 추가

플레이어가 승리할 경우 10% 확률로 추가 점수(+1점) 획득

기본 승점 1점 + 크리티컬 보너스 점수 1점 → 총 +2점 가능

게임에 랜덤성과 재미 요소(twist)를 추가하여 기존 “단조롭다”는 피드백 해결

🎉버그 수정 작업, 승리 팝업 개선 (Win Popup Improvements)
2. 승리 팝업 UI 개선

포켓몬 이미지 아래의 닫기 버튼이 너무 작고 글씨가 안 보인다는 피드백 반영

버튼에 padx, pady 확대 적용하여 가독성 향상

텍스트 크기를 더 키워 시인성 증가

팝업 레이아웃을 조정해 전체적으로 보기 쉬운 UI 구현

🕹️ 게임 밸런스 및 게임성 향상
3. 승리 시 점수 증가 방식 개선

단순 1점 증가 → 상황에 따른 1점 또는 2점 증가

게임의 전략성 + 보상감 강화

🛠️ 기타 코드 정리 및 최적화

일부 Label, Button 배치를 정리하여 가독성 및 유지보수성 향상

가독성을 위한 주석 보강 및 미세한 레이아웃 개선
