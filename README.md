가위바위보 - 하나빼기 (Python Tkinter + PokeAPI 연동 게임)
본 프로젝트는 Python의 Tkinter GUI 라이브러리를 활용하여 제작한
전략형 가위바위보 '하나빼기' 게임입니다.
또한, 플레이어가 승리했을 때 PokeAPI를 통해 랜덤 포켓몬 이미지를 불러오는 기능을 포함하여
게임의 몰입감을 높였습니다.

🎮 프로젝트 개요
일반적인 가위바위보와 달리, 이 게임은 하나빼기 규칙을 적용합니다.

✔ 하나빼기 규칙
플레이어는 두 개의 패(가위/바위/보) 를 고른다.
컴퓨터도 두 개의 패를 무작위로 선택한다.
컴퓨터의 두 패가 먼저 공개된다.
플레이어는 본인이 고른 두 패 중 최종적으로 남길 패 하나를 선택한다.
컴퓨터는 플레이어의 두 패를 기반으로 AI 로직으로 최적의 선택을 계산하여 패를 선택한다.
가위바위보 승패가 결정된다.
플레이어가 승리하면 포켓몬 축하 팝업이 뜬다.
🧠 AI 의사결정 로직 설명
컴퓨터는 단순 무작위가 아니라 다음 전략을 사용합니다:

플레이어가 선택한 2개 손을 기반으로,
각각을 컴퓨터의 패와 비교하여 유리한 패를 선택한다.
플레이어가 가질 수 있는 최대 결과를 예상하여
그 값을 역이용해 플레이어의 승리를 최소화하는 패를 선택한다.
즉, 컴퓨터는 플레이어 최종 선택의 최악 케이스를 반영한 미니맥스(Minimax) 형태의 간단한 전략 AI를 사용한다.

🖥️ GUI 구성 요소
Tkinter로 구현된 GUI는 다음과 같은 요소들로 구성된다:

✔ 주요 화면 구성
정보 안내 라벨
플레이어의 첫 번째/두 번째 손 선택 버튼
컴퓨터의 두 패 공개 영역
플레이어가 최종적으로 선택하는 버튼
승패 결과 표시 영역
스코어(플레이어 vs 컴퓨터)
다시하기 버튼
승리 시 포켓몬 팝업 창
🖼️ PokeAPI 활용
플레이어가 승리하면 다음 순서로 포켓몬이 등장한다:

PokeAPI (https://pokeapi.co/api/v2/pokemon/ID) 에서 랜덤 포켓몬 JSON 조회
스프라이트 이미지 URL 추출
URL로 이미지 다운로드
Base64 변환 후 Tkinter PhotoImage 로 표시
팝업 창에 확대된 포켓몬 이미지 출력
만약 API 오류가 나더라도 게임이 멈추지 않도록 예외 처리 포함.
